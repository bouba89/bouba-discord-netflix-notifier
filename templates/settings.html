📅 Période de vérification

1 jour(s)
ℹ️ Comment ça marche :
• Le bot examine les N × 10 premiers items de chaque liste
• DAYS_BACK = 1 → 10 items examinés (recommandé pour usage quotidien)
• DAYS_BACK = 7 → 70 items examinés (pour usage hebdomadaire)
• Plus la valeur est élevée, plus vous risquez de recevoir de notifications

🧹 Purge des expirés

Supprime uniquement les entrées plus vieilles que DAYS_BACK jours.
Les contenus récents restent en mémoire.

💥 Vider tout le cache

Efface tous les IDs mémorisés. Le prochain run renverra
toutes les nouveautés disponibles dans la liste.
ℹ️ Si le bot ne log plus de nouvelles sorties, c'est souvent parce que le cache est saturé. La purge des expirés suffit dans la plupart des cas.
